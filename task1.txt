1. What is a variable in JavaScript?
1.answer: A variable is a container used to store data or values in a program.

2. What are the three keywords used to create variables?
2.answer: The three keywords are:
var
let
const

3. Write the syntax to create a variable using var.
3.answer: Syntax to create a variable using var:

4. Write the syntax to create a variable using let.
4. answer: Syntax to create a variable using let:

5. Write the syntax to create a variable using const.
5. answer: Syntax to create a variable using const:

6. What is declaration?
6. answer: Declaration means creating a variable without giving it a value.

7. What is initialization?
7. answer: Initialization means giving a value to a variable when it is created.

8. What is reassignment?
8. answer: Reassignment means changing the value of an existing variable.

9. What is redeclaration?
9. answer: Redeclaration means declaring the same variable again using the same keyword.

11. answer: var and let allow reassignment.
